# 홈페이지 DB 연결 — 남은 일

2026-11-26 기준. 홈페이지(newhancyber) · LMS 관리자(newhancyber-lms) · CDMS(cdms) 가 같은 Azure SQL `hancyber-lms` 를 쓴다.
홈페이지가 쓰는 것은 모두 LMS 관리자 화면에 남도록 LMS 코드의 표 · 상태 이름을 그대로 쓴다.

## 연결된 것 (feat/db-connect)

| 기능 | 홈페이지 | LMS |
|---|---|---|
| 학기 · 과목 | 메인 「지금 모집 중」, 수강신청 (학사일정 · 차수 · 과목) | 학사일정 · 차수 · 과목 관리 |
| 장바구니 | 담기 · 빼기 (`cart_items`, 로그인 필요) | 결제 관리 › 장바구니 현황 (LMS 저장소) |
| 결제 | 결제하기 — **PG 없이 바로 결제 완료** (관리자 메모로 표시) | 결제 관리 |
| 쿠폰 | 쿠폰 번호 등록 · 결제 적용 · 사용내역 | 쿠폰 관리 · 발행 관리 · 결제 상세 「이 결제에 쓴 쿠폰」 |
| 결제 · 환불 내역 | 마이페이지 결제 내역 · 결제 상세 · 영수증 · 환불 내역 | — |
| 환불 신청 | 환불 신청 (4단계 자동 계산) | 환불 관리 |
| 장학 | 장학 신청 (증빙 파일 DB 저장) · 장학 현황 | 장학 관리 |
| 나의 강의실 | 진행 중 · 종료 과목, 과목 강의실 (평가 · 출석 합계 · 차시) | 수강 관리 |
| 시험 · 과제 | 시험(중간 · 기말 · 퀴즈) 응시 · 자동 채점, 과제 · 토론 · 학습심화활동 글 제출 | 수강 관리 › 각 평가 관리 · 채점 |
| 강의 | 학습창 (CDMS 영상 서명 재생 · 목차 · 자막) · 학습 기록(80% = 완료) → 진도율 · 출석 | 수강 관리 (진도율) |
| 강의 평가 · 성적 | 강의 평가(과목 만족도 설문 응답) · 성적 보기(평가를 마쳐야 · 확정 성적은 conf_grades 반영 점수) · 강의계획서 · 주차별 출석 | 과목 관리 › 설문 관리 › 결과 · 성적 보고 |
| 내 정보 수정 | 비밀번호 확인(로그인과 같은 잠금 · 10분 통과증) → 연락처 · 주소 · 학력 · 수신 동의 · 비밀번호 저장 | 회원 관리 (마지막 수정) |
| 학습 게시판 | 학습 공지사항 · 학습 자료실 목록(학기 · 과목 · 검색) · 글 보기 · 첨부 받기 — 내 수강 차수 · 대상 모두/학습자 글만, 조회수 | 학습 게시판 관리 (교강사 사이트 같은 글) |

새 표 (서버 관리자 계정으로 만듦 — `newhancyber-db` 의 `sql/schema/` 에도 넣을 것):

- [ ] **과제 첨부 파일** — LMS · 교강사 사이트에 파일을 받아 볼 곳(표 · 내려받기)이 없다. 저장 방식(DB · R2) 정하기
- [ ] **증명서** — 수강확인서 · 성적증명서 · 수료증(`certificate_templates` · `certificate_issues`) · 교육비 납입 증명서
- [ ] 수요조사(마이페이지 설문) · 수강후기 쓰기 · 이의신청 · 예외처리 · PC 등록 목록 · 증명서 · 실습 서류

- [ ] 아이디 찾기 · 비밀번호 재발급 — 문자 발송 업체(또는 본인 인증) 붙인 뒤에 (사용자 결정 11/26). 화면에 임시 비밀번호를 보여 주지 않는다

## 알아둘 것

- 개발 서버(`npm run dev`)는 셸로 파일을 고치면 옛 모듈을 계속 쓸 때가 있다 — 화면이 코드와 다르면 다시 켠다
- 앱 안 브라우저는 확인 창 · 알림 창(confirm · alert)을 막는다 — 결제 · 시험 등은 화면 안 안내로 바꿨다
