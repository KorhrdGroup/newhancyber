## 외부 계약 · 정할 것

- [ ] **나이스페이** — 지금은 결제 수단과 상관없이 바로 결제 완료. 붙이면: 「입금 대기」로 만들고 → PG 승인 · 가상계좌 입금 통보에서 결제 완료 · `pg_tid` 등 채우기
- [ ] 문자 발송 업체 · 본인 인증(NICE · PASS) — 아이디 · 비밀번호 찾기, 본인 인증 관리(LMS 「본인 인증 관리」 표는 비어 있다)
- [ ] 과목에 강의 평가 설문 연결 — 지금 어떤 과목에도 과목 만족도 설문이 없다 (LMS 설문 관리에서 만들고 과목에 고르기). 없으면 성적은 바로 보인다
- [ ] 회원 탈퇴 — 처리 규칙(수강 · 결제 기록 보관, 계정 사용 중지)이 정해지지 않아 지금은 1:1 문의 안내
- [ ] 과제 첨부 파일 — LMS · 교강사 사이트에 파일을 받아 볼 곳이 없다. 저장 방식(DB · R2) 정하기
- [ ] 강의 출석을 「주차 기간 안에 들어야 인정」으로 바꿀지 (지금은 완료 차시 수)
- [ ] 시험 시간 제한 (평가 표에 시험 시간 칸이 없어 기간으로만 막는다)
- [ ] CDMS 교안(PDF · MP3)을 R2 로 옮긴 뒤 학습창에 연결
- [ ] 개발 · 운영이 같은 DB — 운영 전에 개발용 DB 분리 검토
